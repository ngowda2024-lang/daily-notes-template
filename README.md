# Daily Notes Template

A lightweight Markdown template for planning a day and capturing notes. Copy the template below into a new file named with the date, such as `2026-11-21.md`.

## Daily template

```markdown
# YYYY-MM-DD

## Top priorities
- [ ]
- [ ]
- [ ]

## Schedule
- 

## Notes

## End-of-day review
- Done today:
- Carry forward:
- Reflection:
```

This repository is a starter template. Adapt the sections to your own workflow.
